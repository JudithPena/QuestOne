# QuestOne

**Одинокая крепость**: текстовое приключение в стиле D&D для телефона, по мотивам модуля «Первый взгляд» (D&D Duet).

Один герой, воин Йорик, проходит 10 сцен в двух актах (замок в Амне и Одинокая крепость в Облачных пиках). В игре есть проверки к20 со сложностью, пошаговые бои, союзник Гаррен и две концовки. Прогресс сохраняется в браузере.

Чтобы играть, откройте `index.html` в любом браузере. Это один файл без зависимостей.

## Затерянные рудники Фанделвера

Папка `phandelver/`: большая текстовая игра по стартовому модулю D&D 5e для одного героя с напарником.

- Выбор расы (человек, дварф, эльф, полурослик) и класса (воин, плут, жрец, волшебник), уровни с 1 по 5.
- Проверки навыков к20, пошаговые бои с несколькими врагами, заклинания, напарники (Сильдар, Друп).
- Инвентарь, лавки, журнал заданий, короткий и длительный отдых, автосохранение и повтор боя.
- Сейчас готовы главы 1 (Гоблинские стрелы) и 2 (Фандалин, убежище Красноклеймённых). Главы 3 и 4 будут добавлены.

Чтобы играть, откройте `phandelver/index.html` в браузере. Скрипт `phandelver/build-artifact.sh` собирает копию для публикации.
